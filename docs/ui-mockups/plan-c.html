方案 C · 留白

核心思路：把界面当成一张纸，而不是一堆控件。取消顶栏底色，改用 26px 大标题定调； 列表是无边框的行，组与组之间靠留白区分；品牌蓝只用来标记「当前选中」， 分类色只画 3px 竖条不画色块；课表从「七天网格」改成「今日时间线」， 日历从「月格子」改成「竖向日程流」。
颜色系统与方案 A 同源，但更克制 —— 页面里同时出现的颜色种类最少。

方案 C 相对现状改了什么

  1. 顶栏全部去底色。现状清单页顶栏是纯 primaryContainer、课表页是渐变、习惯页是裸 TopAppBar（TaskScreen.kt:183 / TimetableScreen.kt:101 / HabitScreen.kt:74），三页三种长相；方案 C 统一成「白底 + 26px 大标题」，问题直接从源头消失。
  2. 课表从网格改成时间线。现状 7 列硬挤在 360dp 屏里（每列约 43dp，扣完 padding 只剩 35dp，课程名 12sp 中文只能露 3 个字），且没有任何当前时刻线；方案 C 默认给「今天」的时间线，横向日期条切周，文字全部读得全。
  3. 日历从月格子改成竖向日程流。现状一格里塞了日期圆 + 4 个 4dp 圆点 + 农历角标 + 选中描边四条通道（MonthDayCell.kt:62-128），4 个点共 16dp 挤在约 40dp 格内几乎不可辨；方案 C 里每条日程一行，圆点 7px + 完整文字。
  4. 颜色种类压到最少。分类色只画 3px 竖条（不再有彩色圆点 + 彩色胶囊 + 彩色底三种表达并存，ChecklistItem.kt:248-291），品牌蓝只出现在「选中态 / 主操作 / 当前时刻之外的强调」，页面同时可见的颜色种类从 8 种降到 4 种。
  5. 金额用 44px 细字重而不是 36px 粗体，数字本身就是主角，不需要再给它一个卡片底色来强调。
  6. 记账不再有四张卡：今日剩余一行大字、概览折进「报表 / 零钱池 / 预算」标签页，流水直接跟在下面。
  7. 保留：颜色语义封闭系统、触控目标 ≥ 44dp、字号 ≥ 10px，这三点与方案 A、B 一致 —— 三套方案的差别只在布局语言，不在可达性底线。
方案 C · 留白 —— 静态原型（HTML/CSS，无交互逻辑）。
另有 方案 A · 秩序、方案 B · 紧凑、融合版 D（C 打底 + 课表双视图 + 今日剩余卡），返回总览对比。
