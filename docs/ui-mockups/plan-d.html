融合版的具体设计决策

  1. 颜色 token 全部沿用 C，只补两个 A 的语义色：--warn #7A4A00（预算临界）与 --transfer #4A5560（转账）。 收入 #2E6B33、支出 #B23A2E、当前时刻 #B45309 跟 C 一致，全部不跟随用户主题色。
  2. 今日剩余卡：结构照 A（标题行 + 口径切换胶囊 + 大金额 + 预算/已用副行 + 进度条 + 脚注）， 皮肤换成 C —— 底色 #F7F6F3 暖白，左侧 3px 品牌蓝竖条，金额 34px 细字重（原 A 是 36px 粗体）。 金额三档色：正常 --text / 接近预算 --warn / 超支 --expense。
  3. 课表两个视图共用同一个标题区，切换靠标题下方的下划线标签「时间线 / 整周网格」—— 和记账页的「流水 / 报表 / 零钱池 / 预算」是同一套控件语言。
  4. 时间线视图：C 原样。横向日期条选日期，下面竖向时间线；当前时刻那一行用 --now 琥珀色标出， 显示「今天还有 0 节课」这类即时信息而不是硬塞一个时间戳。
  5. 网格视图：列宽 60dp（现状 43dp），整周 420px 横向可滑，左侧 44dp 时间轴固定不动， 星期表头跟网格一起滑。课程卡按 C 的语言重画：13% 淡色底 + 3px 实色左条 + 深色文字， 不再用现状那种 18% 底 + 0.6 alpha 描边（描边在浅底上会显脏）。补上现状完全缺失的当前时刻线（琥珀色 + 左端圆点）。
  6. 网格视图下方保留「今日课程」竖排列表 —— 网格能看分布，竖排能读全，两者互补； 这也是「可切换」的实际价值所在。
  7. 其余四个模块（清单 / 日历 / 习惯 / 我的）与纯 C 版一致，一行未改 —— 融合点越少，落地时的回归面越小。
融合版 D —— 静态原型（HTML/CSS，无交互逻辑）。
