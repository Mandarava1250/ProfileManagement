# Phase 26 UI 改造 · 人工验收清单

> 适用范围：方案 D 的全部落地改动（P0 令牌层 → P8 收口）
> 验证环境：Android 真机或可显示的模拟器（本机 AVD `aosp_atd` 镜像全黑屏，**不可用**）
> 每屏按「浅色 / 深色」各走一遍

## 0. 全局基线（每屏都要先扫一眼）

| # | 检查项 | 判定标准 |
|---|---|---|
| 0.1 | 页面底色 | 暖白 `#F7F6F3`（浅色）/ 深灰（深色），不是纯白 |
| 0.2 | 语义色是否随主题变 | 收入绿 `#2E6B33`、支出红 `#B23A2E`、转账灰 `#4A5560`、临界棕 `#7A4A00`、当前时刻棕 `#B45309` —— **切换主题时这些色不变** |
| 0.3 | 「当前时刻」线 | 课表 / 日历里的「现在」线是**棕橙色**，不是红色（红色 = 冲突 / 逾期） |
| 0.4 | 大标题 | 26sp / 700，行标题 15.5sp，正文 15sp，次要 11.5sp，分组标题 13.5sp |
| 0.5 | 最小字号 | 任何文字都 ≥ 10sp（重点看月历农历角标） |
| 0.6 | 触达 | 所有可点元素 ≥ 44dp（重点看习惯打卡 ±、清单筛选按钮） |
| 0.7 | 卡片圆角 | 14dp；chip 8dp；内联按钮圆 20dp |
| 0.8 | 纵向条 | 分类 / 课程 / 事件色条统一 3dp 宽，**只在左边**，四边不描框 |

## 8. 已知取舍（不必报 bug）

1. **课表副标题的「⌄」目前是静态字符**，还没做成真的下拉 —— 学期切换仍走下方那一行 `SemesterSelector`。
2. **日历的日程流目前按选中日聚合**，不是整周滚动。组件本身支持多天（`AgendaStream(days = List<AgendaDay>)`），接上区间观察流即可扩。
3. **月 / 周 / 日三种网格是标签页，不是独立路由** —— 功能没丢，但没做成「二级页」。
4. **课表 modifier 顺序的回归测试只覆盖到算式层**（`TimetableLayoutTest`），Modifier 链本身的顺序要 instrumented test 才量得到；3.1 这条得真机看一眼。
5. `docs/ui-mockups/plan-d.html` 原型**已同步到实现**（D1 抽屉入口 + 近 7 天完成率 / D3 只留课程 / D5 日程流 + 四标签 / D7 账户名副行）。
